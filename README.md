# Kisilestirilmis_Oneri_Sistemi
Kişiselleştirilmiş Hobi ve Aktivite Öneri Sistemi
Bu proje, kullanıcıların ilgi alanlarına ve günlük boş zamanlarına göre onlara en uygun hobi ve aktiviteleri öneren yapay zeka tabanlı bir sistemdir.

Kullanıcıların dijital yorgunluğunu azaltmak ve boş zamanlarını daha verimli değerlendirmelerini sağlamak amacıyla geliştirilmiştir. Sistem, kullanıcı tercihlerini analiz ederek kişiye özel planlar oluşturur.

Kullanılan Teknolojiler
Proje Yönetimi: Jira (Kanban Metodolojisi)
Versiyon Kontrolü: Git & GitHub
Programlama Dili: Python (Veri işleme ve modelleme için)
Yapay Zeka: Scikit-learn / TensorFlow (Öneri algoritması için)

Öne Çıkan Özellikler
Kullanıcı ilgi alanı seçimi.
Günlük boş zaman takvimi entegrasyonu.
Akıllı aktivite eşleştirme algoritması.
Sade ve kullanıcı dostu arayüz.
